# Modul Analisis — fondasi engine, deteksi fase, kurva peluang, hasil sesi, konvensi evaluasi, keamanan bidak, buku pembukaan, penilaian langkah, metrik akurasi, langkah kritis, ringkasan analisis, wawasan profil, konstanta MultiPV, dasar anti-cheat, kalibrasi anti-cheat, dan skor anti-cheat

Modul ini bagian dari modular monolith, bukan layanan terpisah. Cakupan saat ini **hanya** daftar pilihan dan pembungkus worker `EngineCatur`, pemeriksaan WASM dan ukuran hash, deteksi fase permainan (`deteksiFase.js`), kurva peluang menang (`kurvaPeluang.js`), pendaftaran hasil analisis sesi di memori (`hasilSesi.js`), konvensi evaluasi langkah dan skor UCI (`konvensiEvaluasi.js`), fasad internal deteksi penyerang tersembunyi/baterai (`bateraiBidak.js` melalui `keamananBidak.js`), pemuat dan pencari nama buku pembukaan (`bukuPembukaan.js` melalui `buku.js`), klasifikasi kualitas langkah, deteksi pengorbanan, dan langkah paksa (`penilaianLangkah.js` melalui `penilaian.js`), metrik akurasi, centipawn loss, anotasi NAG, dan agregasi harmonik (`metrikAkurasi.js` melalui `akurasi.js`), deteksi langkah kritis MultiPV (`deteksiLangkahKritis.js` melalui `langkahKritis.js`), ringkasan hasil analisis satu partai per warna (`ringkasPartai.js` melalui `ringkasanAnalisis.js`), agregasi wawasan profil pemain (`wawasanProfil.js` melalui `wawasan.js`), konstanta pencarian MultiPV (`konstantaMesin.js` melalui `multiPv.js`), lapisan dasar anti-cheat (`dasarAntiCheat.js` melalui `antiCheatDasar.js`), kalibrasi komponen anti-cheat (`kalibrasiAntiCheat.js` melalui `antiCheatKalibrasi.js`), serta skor per partai anti-cheat (`skorAntiCheat.js` melalui `antiCheatSkor.js`). Parser, `laporanPeninjauan.js`, lapisan teratas `antiCheat` (`agregat`, fasad `antiCheat.js`), adaptor `EngineAnalisis`, provider Mesin, komponen visual dan bagian Analisis lain tetap pada path masing-masing; tidak ada pemindahan massal atau perubahan skema data/cache.

## Kontrak lama yang dipertahankan

- Enam objek pilihan tetap berurutan dengan ID, label, Elo, keterangan, URL, dan Stockfish 18 Lite sebagai default yang sama. URL dibentuk saat modul dimuat menggunakan base path saat itu. `cariEngine` memakai pencocokan ID ketat dan mengembalikan objek asli, bukan salinan; ID yang tidak dikenal memilih default.
- Array dan objek pilihan tetap dapat dimutasi. Bila ada ID duplikat, pencarian memilih entri pertama; jika objek default telah dihapus, fallback dapat menghasilkan `undefined`. Ini adalah perilaku lama, bukan validasi atau jaminan bahwa daftar boleh diubah oleh fitur baru.
- `EngineCatur` menyimpan state per instance dan memuat worker secara malas. Panggilan startup berbagi promise, mengirim perintah UCI awal dengan opsi NNUE untuk Stockfish 16, serta dapat dicoba kembali setelah gagal. Pesan `readyok` sendiri masih menyelesaikan startup sekalipun `uciok` belum diterima. `setop()` menolak permintaan tertunda dan mengirim `stop` untuk pencarian aktif; pencarian aktif masih menunggu `bestmove` atau galat/terminasi. Antrean, parser info/MultiPV, callback, pembersihan dan pesan galat tetap seperti implementasi lama.
- `wasmSupported` meneruskan hasil validator dan galat yang dilemparkannya.
