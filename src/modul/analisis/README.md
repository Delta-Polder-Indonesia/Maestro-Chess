# Modul Analisis — fondasi engine

Modul ini bagian dari modular monolith, bukan layanan terpisah. Cakupan saat ini **hanya** daftar pilihan dan pembungkus worker `EngineCatur`, serta pemeriksaan WASM dan ukuran hash. Parser, klasifikasi, adaptor `EngineAnalisis`, cache hasil analisis, buku, provider Mesin, komponen visual dan bagian Analisis lain tetap pada path masing-masing; tidak ada pemindahan massal atau perubahan skema data/cache.

## API, identitas, dan dependensi

- `mesin.js` adalah fasad ringan tanpa JSX dengan tujuh ekspor bernama: `DAFTAR_ENGINE`, `ENGINE_BAKU`, `cariEngine`, `EngineCatur`, `wasmSupported`, `wasmThreadsSupported`, dan `hashUntukEngine`. `index.js` meneruskan tujuh ekspor yang sama. Tidak ada ekspor default.
- `src/lib/engineCatur.js` tetap meneruskan tepat empat ekspor bernama awal, langsung ke `engineCatur.js`; `src/halaman/Analisa/mesin/cekWasm.js` tetap meneruskan tepat tiga ekspor bernama awal, langsung ke `cekWasm.js`. Semua path dalam registry modul yang sama berbagi identitas array, objek pilihan, fungsi, dan kelas, bukan salinan. Identitas satu registry tidak menjamin singleton lintas proses, bundle terisolasi, atau salinan modul dengan URL berbeda.
- Fasad hanya memuat kedua implementasi dan `src/lib/asets.js` untuk membentuk URL publik. Ia tidak memuat React, JSX, provider, fitur lain, storage, atau adaptor `EngineAnalisis`. Impor dan konstruksi tidak membuat worker atau membaca kemampuan browser; worker dibuat ketika `mulai()` dipanggil.
- Lima pemanggil aplikasi menggunakan `mesin.js`: adaptor `src/halaman/Analisa/mesin/engine.js`, provider `konteks/mesin.jsx`, pengaturan `komponen/pengaturan/mesin.jsx`, `komponen/nav/layarEngine.jsx` dan `komponen/nav/layarDeteksiEngine.jsx`. Ketiganya yang terakhir adalah komponen visual yang tetap di tempatnya. Tidak ada context, provider, atau hook baru; `KonteksMesin`, `useMesin` dan `MesinProvider` mempertahankan identitas dan lokasi Tahap 11. Provider masih menggunakan `EngineAnalisis` pada path lama; modul Sesi tidak mengimpor implementasi engine lama.

## Kontrak lama yang dipertahankan

- Enam objek pilihan tetap berurutan dengan ID, label, Elo, keterangan, URL, dan Stockfish 18 Lite sebagai default yang sama. URL dibentuk saat modul dimuat menggunakan base path saat itu. `cariEngine` memakai pencocokan ID ketat dan mengembalikan objek asli, bukan salinan; ID yang tidak dikenal memilih default.
- Array dan objek pilihan tetap dapat dimutasi. Bila ada ID duplikat, pencarian memilih entri pertama; jika objek default telah dihapus, fallback dapat menghasilkan `undefined`. Ini adalah perilaku lama, bukan validasi atau jaminan bahwa daftar boleh diubah oleh fitur baru.
- `EngineCatur` menyimpan state per instance dan memuat worker secara malas. Panggilan startup berbagi promise, mengirim perintah UCI awal dengan opsi NNUE untuk Stockfish 16, serta dapat dicoba kembali setelah gagal. Pesan `readyok` sendiri masih menyelesaikan startup sekalipun `uciok` belum diterima. `setop()` menolak permintaan tertunda dan mengirim `stop` untuk pencarian aktif; pencarian aktif masih menunggu `bestmove` atau galat/terminasi. Antrean, parser info/MultiPV, callback, pembersihan dan pesan galat tetap seperti implementasi lama.
- `wasmSupported` meneruskan hasil validator dan galat yang dilemparkannya. Jika global `WebAssembly` bernilai `null`, ia tetap melempar `TypeError`. `wasmThreadsSupported` tetap memeriksa kemampuan memori bersama tanpa menjadikannya syarat engine single-thread. `hashUntukEngine` tetap memilih 16 MB untuk perangkat seluler atau memori numerik hingga 2 GiB dan 32 MB pada kondisi desktop/default yang dikarakterisasi; `navigator` bernilai `null` tetap melempar. Temuan ini dicatat, bukan diperbaiki diam-diam.

## Pengujian dan batas

`tests/analisa-fondasi-mesin-karakterisasi.test.mjs` dijalankan terhadap implementasi pada path asli sebelum migrasi dan tetap menguji kedua path kompatibilitas. `tests/analisa-fondasi-mesin-batas.test.mjs` memeriksa ekspor dan identitas, graf fasad, definisi tunggal, pemanggil, impor server dan integrasi adaptor lama. Tes lainnya menjalankan keenam engine sebenarnya melalui UCI di proses Node, termasuk NNUE; karakterisasi kelas menggunakan Worker tiruan. Ini bukan verifikasi browser Worker, visual, jaringan nyata, atau data pengguna. Pemeriksaan import statis tidak membuktikan semua URL runtime atau cabang browser.
