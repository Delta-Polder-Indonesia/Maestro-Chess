# Modul Analisis — fondasi engine, deteksi fase, kurva peluang, hasil sesi, konvensi evaluasi, dan keamanan bidak

Modul ini bagian dari modular monolith, bukan layanan terpisah. Cakupan saat ini **hanya** daftar pilihan dan pembungkus worker `EngineCatur`, pemeriksaan WASM dan ukuran hash, deteksi fase permainan (`deteksiFase.js`), kurva peluang menang (`kurvaPeluang.js`), pendaftaran hasil analisis sesi di memori (`hasilSesi.js`), konvensi evaluasi langkah dan skor UCI (`konvensiEvaluasi.js`), serta fasad internal deteksi penyerang tersembunyi/baterai (`bateraiBidak.js` melalui `keamananBidak.js`). Parser, klasifikasi (`penilaian.js`), akurasi (`akurasi.js`), adaptor `EngineAnalisis`, buku, provider Mesin, komponen visual dan bagian Analisis lain tetap pada path masing-masing; tidak ada pemindahan massal atau perubahan skema data/cache.

## API, identitas, dan dependensi

- `mesin.js` adalah fasad ringan tanpa JSX dengan tujuh ekspor bernama: `DAFTAR_ENGINE`, `ENGINE_BAKU`, `cariEngine`, `EngineCatur`, `wasmSupported`, `wasmThreadsSupported`, dan `hashUntukEngine`.
- `fase.js` adalah fasad ringan tanpa JSX/React dengan delapan ekspor bernama: `FASE_PEMBUKAAN`, `FASE_MENENGAH`, `FASE_AKHIR`, `DAFTAR_FASE`, `isEndOpening`, `isEndMiddlegame`, `faseBerikutnya`, dan `papanDariFen`.
- `peluang.js` adalah fasad ringan murni matematika dengan empat ekspor bernama: `CP_CEILING`, `FAKTOR_PELUANG`, `batasiCp`, dan `peluangMenang`.
- `analisisTersimpan.js` adalah fasad ringan tanpa JSX/React dengan enam ekspor bernama: `catatAnalisis`, `hapusAnalisis`, `bersihkanAnalisis`, `ambilPetaAnalisis`, `jumlahAnalisis`, dan `langgananAnalisis`.
- `evaluasi.js` adalah fasad ringan tanpa JSX/React/`chess.js` dengan sembilan ekspor bernama: `STATUS_EVALUASI`, `MATE_DISAMPAIKAN`, `normalisasiEval`, `apakahMateTerminal`, `tandaMate`, `cpBaku`, `evalSiap`, `langkahTerpaksa`, dan `ratingTampilan`.
- `keamananBidak.js` adalah fasad internal tanpa JSX/React/`EngineAnalisis` dengan satu ekspor bernama: `penyerangTersembunyi` (diteruskan dari `./bateraiBidak.js`). Karena saat ini merupakan helper khusus untuk `penilaian.js`, simbol ini **tidak** diekspor pada barrel publik `index.js`.
- `index.js` tetap meneruskan ketiga puluh empat ekspor bernama dari `mesin.js`, `fase.js`, `peluang.js`, `analisisTersimpan.js`, dan `evaluasi.js`. Tidak ada ekspor default pada seluruh berkas modul Analisis.
- `src/lib/engineCatur.js` tetap meneruskan tepat empat ekspor bernama awal langsung ke `engineCatur.js`; `src/halaman/Analisa/mesin/cekWasm.js` meneruskan tepat tiga ekspor bernama awal langsung ke `cekWasm.js`; `src/halaman/Analisa/mesin/fase.js` meneruskan tepat delapan ekspor bernama awal langsung ke `deteksiFase.js`; `src/halaman/Analisa/mesin/peluang.js` meneruskan tepat empat ekspor bernama awal langsung ke `kurvaPeluang.js`; `src/halaman/Analisa/mesin/analisisTersimpan.js` meneruskan tepat enam ekspor bernama awal langsung ke `hasilSesi.js`; `src/halaman/Analisa/mesin/evaluasi.js` meneruskan tepat sembilan ekspor bernama awal langsung ke `konvensiEvaluasi.js`; `src/halaman/Analisa/mesin/keamananBidak.js` meneruskan tepat satu ekspor bernama awal langsung ke `bateraiBidak.js`. Semua path dalam registry modul yang sama berbagi identitas array, objek pilihan, objek konstanta beku, fungsi, kelas, serta singleton peta hasil dan set pendengar sesi, bukan salinan. Identitas satu registry tidak menjamin singleton lintas proses, bundle terisolasi, atau salinan modul dengan URL berbeda.
- Fasad `mesin.js` hanya memuat dua implementasi engine/WASM dan `src/lib/asets.js`; fasad `fase.js` hanya memuat `deteksiFase.js` dan `chess.js`; fasad `peluang.js` hanya memuat `kurvaPeluang.js` tanpa paket pihak ketiga; fasad `analisisTersimpan.js` hanya memuat `hasilSesi.js` tanpa paket pihak ketiga; fasad `evaluasi.js` hanya memuat `konvensiEvaluasi.js`, `peluang.js`, dan `kurvaPeluang.js` tanpa paket pihak ketiga; fasad `keamananBidak.js` hanya memuat `bateraiBidak.js` dan `chess.js`. Keenamnya maupun `index.js` tidak memuat React, JSX, provider, fitur lain, storage, atau adaptor `EngineAnalisis`. Impor dan konstruksi tidak membuat worker atau membaca kemampuan browser; worker dibuat ketika `mulai()` dipanggil.
- Lima pemanggil aplikasi menggunakan `mesin.js`: adaptor `src/halaman/Analisa/mesin/engine.js`, provider `konteks/mesin.jsx`, pengaturan `komponen/pengaturan/mesin.jsx`, `komponen/nav/layarEngine.jsx`, dan `komponen/nav/layarDeteksiEngine.jsx`.
- Empat pemanggil aplikasi menggunakan `fase.js`: `komponen/menu/analysis/summary/playersAccuracy.jsx`, `komponen/nav/ringkasanAntiCheat.jsx`, `mesin/antiCheat/agregat.js`, dan `mesin/antiCheat/skor.js`.
- Tiga pemanggil langsung menggunakan `peluang.js`: `src/modul/analisis/konvensiEvaluasi.js`, `mesin/penilaian.js`, dan `mesin/akurasi.js` (yang tetap mengekspor ulang keempat simbol tersebut ke `antiCheat.js` dan `langkahKritis.js`).
- Dua pemanggil aplikasi menggunakan `analisisTersimpan.js`: `komponen/game/useMuatPartai.js` (`catatAnalisis`) dan `komponen/nav/layarWawasan.jsx` (`ambilPetaAnalisis`, `langgananAnalisis`); `hapusAnalisis`, `bersihkanAnalisis`, dan `jumlahAnalisis` tetap diekspos sebagai bagian kontrak publik modul.
- Empat belas pemanggil aplikasi menggunakan `evaluasi.js`: delapan komponen/hook UI (`komponen/game/evaluation.jsx`, `komponen/game/game.jsx`, `komponen/game/useAnalisisPapan.js`, `komponen/menu/analysis/gameChart.jsx`, `komponen/menu/analysis/moves/comments.jsx`, `komponen/menu/analysis/moves/moves.jsx`, `komponen/menu/analysis/summary/playersAccuracy.jsx`, `komponen/menu/analysis/summary/ratingCount.jsx`) serta enam berkas mesin/anti-cheat (`mesin/akurasi.js` yang juga tetap mengekspor ulang `cpBaku`, `mesin/antiCheat/dasar.js`, `mesin/antiCheat/skor.js`, `mesin/engine.js`, `mesin/penilaian.js`, dan `mesin/ringkasanAnalisis.js`).
- Satu pemanggil aplikasi menggunakan fasad internal `keamananBidak.js`: `src/halaman/Analisa/mesin/penilaian.js` (`penyerangTersembunyi`). Tidak ada context, provider, atau hook baru; `KonteksMesin`, `useMesin`, dan `MesinProvider` mempertahankan identitas dan lokasi Tahap 11. Provider masih menggunakan `EngineAnalisis` pada path lama; modul Sesi tidak mengimpor modul Analisis maupun implementasi engine lama.

## Kontrak lama yang dipertahankan

- Enam objek pilihan tetap berurutan dengan ID, label, Elo, keterangan, URL, dan Stockfish 18 Lite sebagai default yang sama. URL dibentuk saat modul dimuat menggunakan base path saat itu. `cariEngine` memakai pencocokan ID ketat dan mengembalikan objek asli, bukan salinan; ID yang tidak dikenal memilih default.
- Array dan objek pilihan tetap dapat dimutasi. Bila ada ID duplikat, pencarian memilih entri pertama; jika objek default telah dihapus, fallback dapat menghasilkan `undefined`. Ini adalah perilaku lama, bukan validasi atau jaminan bahwa daftar boleh diubah oleh fitur baru.
- `EngineCatur` menyimpan state per instance dan memuat worker secara malas. Panggilan startup berbagi promise, mengirim perintah UCI awal dengan opsi NNUE untuk Stockfish 16, serta dapat dicoba kembali setelah gagal. Pesan `readyok` sendiri masih menyelesaikan startup sekalipun `uciok` belum diterima. `setop()` menolak permintaan tertunda dan mengirim `stop` untuk pencarian aktif; pencarian aktif masih menunggu `bestmove` atau galat/terminasi. Antrean, parser info/MultiPV, callback, pembersihan dan pesan galat tetap seperti implementasi lama.
- `wasmSupported` meneruskan hasil validator dan galat yang dilemparkannya. Jika global `WebAssembly` bernilai `null`, ia tetap melempar `TypeError`. `wasmThreadsSupported` tetap memeriksa kemampuan memori bersama tanpa menjadikannya syarat engine single-thread. `hashUntukEngine` tetap memilih 16 MB untuk perangkat seluler atau memori numerik hingga 2 GiB dan 32 MB pada kondisi desktop/default yang dikarakterisasi; `navigator` bernilai `null` tetap melempar. Temuan ini dicatat, bukan diperbaiki diam-diam.
- `DAFTAR_FASE` mempertahankan urutan `["opening", "middlegame", "endgame"]` dan tetap berupa array yang dapat dimutasi. `isEndOpening` mempertahankan ambang pengembangan asimetris pada baris awal putih dan hitam, `isEndMiddlegame` mempertahankan batas jumlah perwira/menteri/benteng, `faseBerikutnya` hanya melangkah satu tahap ke depan (`opening → middlegame → endgame`) dan mengembalikan input apa adanya bila papan kosong atau nilai fase tidak dikenal, serta `papanDariFen` mengembalikan `null` untuk FEN kosong atau tidak valid. Pemanggil tetap mempertahankan perbedaan perilaku lamanya pada langkah paksa di batas fase.
- `CP_CEILING` (`1000`), `FAKTOR_PELUANG` (`-0.00368208`), `batasiCp`, dan `peluangMenang` mempertahankan konstanta serta rumus lichess/en-croissant persis seperti semula, termasuk perbedaan koersi lama (`batasiCp(NaN|undefined|"abc")` tetap mengembalikan `NaN` dan `batasiCp(null|"")` mengembalikan `0`, sedangkan `peluangMenang` memakai `Number(cp) || 0` sehingga input kosong/non-numerik mengembalikan `50`). Identitas fungsi lintas `peluang.js`, `akurasi.js`, dan `antiCheat.js` dipertahankan tanpa penyimpangan.
- `hasilSesi.js` tetap menyimpan peta sesi hanya di memori (`Map` + `Set` pendengar, tidak persisten). `catatAnalisis` memangkas spasi kunci dan mengabaikan kunci kosong, `hasil` falsy, maupun `status !== "complete"` secara diam-diam tanpa notifikasi; `hapusAnalisis` dan `bersihkanAnalisis` tidak memicu pendengar bila entri/peta kosong; `ambilPetaAnalisis` membentuk objek baru setiap panggilan (`Object.fromEntries`) sambil mempertahankan referensi nilai objek hasil; `langgananAnalisis` mengembalikan no-op untuk non-fungsi, memakai semantik `Set`, mengambil snapshot pendengar saat `beriKabar`, dan menelan galat dari masing-masing pendengar.
- `konvensiEvaluasi.js` mempertahankan `STATUS_EVALUASI` (`Object.freeze({ SIAP: "siap", GAGAL: "gagal", DIBATALKAN: "dibatalkan" })`), `MATE_DISAMPAIKAN === 0`, dan seluruh kontrak/koersi lama tanpa normalisasi diam-diam: `tandaMate(0)` mengembalikan `-1` (`tandaMate(null|undefined|"")` → `null`, `tandaMate("   "|false)` → `-1`), `normalisasiEval` menerima warisan `["mate"]` sebagai `["mate", "0"]`, membulatkan angka dengan `Math.trunc`, dan mempertahankan koersi `Number()` (`["cp", "   "]` → `["cp", "0"]`, `["cp", true|false]` → `["cp", "1"|"0"]`), `apakahMateTerminal` menerima `["mate"]` maupun `Number(mentah) === 0` (`"   "`, `false`), `cpBaku` mengembalikan `null` saat `length < 2` (termasuk `["mate"]`), mempertahankan nilai pecahan tanpa `Math.trunc`, tidak memeriksa `"cp"` secara ketat (`["other", "50"]` → `50`), mengembalikan `+1000` untuk `cpBaku(["mate", "0"], true)` dan `-0` untuk `cpBaku(["cp", "0"], true)`, `evalSiap` menerima status `undefined`/`null` dan string non-gagal/batal, serta `langkahTerpaksa` dan `ratingTampilan` mengutamakan `isForced === true` atau `moveRating === "forced"`.
- `bateraiBidak.js` mempertahankan algoritma `penyerangTersembunyi`, `BATAS_RANTAI === 16`, urutan penemuan LIFO, pengecualian raja, pengabaian bidak depan tanpa langkah legal (pin/skak), pemakaian lazy cache `langkahLegal`, non-mutasi papan `Chess` masukan, semantik giliran saat `langkahLegal` tidak diberikan, serta evaluasi `bisaMembuka` terhadap daftar langkah papan awal tanpa perbaikan diam-diam.

## Pengujian dan batas

`tests/analisa-fondasi-mesin-karakterisasi.test.mjs`, `tests/analisa-fase-karakterisasi.test.mjs`, `tests/analisa-peluang-karakterisasi.test.mjs`, `tests/analisa-analisis-tersimpan-karakterisasi.test.mjs`, `tests/analisa-evaluasi-karakterisasi.test.mjs`, dan `tests/analisa-keamanan-bidak-karakterisasi.test.mjs` dijalankan terhadap implementasi pada path asli sebelum migrasi dan tetap menguji path kompatibilitas. `tests/analisa-fondasi-mesin-batas.test.mjs`, `tests/analisa-fase-batas.test.mjs`, `tests/analisa-peluang-batas.test.mjs`, `tests/analisa-analisis-tersimpan-batas.test.mjs`, `tests/analisa-evaluasi-batas.test.mjs`, dan `tests/analisa-keamanan-bidak-batas.test.mjs` memeriksa ekspor dan identitas, singleton bersama, graf fasad, definisi tunggal, pemanggil, impor server, serta batas modul. Tes lainnya menjalankan keenam engine sebenarnya melalui UCI di proses Node, termasuk NNUE; karakterisasi kelas menggunakan Worker tiruan, dan karakterisasi komponen fase/sesi/evaluasi menggunakan React Test Renderer serta terjemahan/provider/buku tiruan. Ini bukan verifikasi browser Worker, visual, jaringan nyata, atau data pengguna. Pemeriksaan import statis tidak membuktikan semua URL runtime atau cabang browser.
